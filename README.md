# A6 Controls - Android Application (Lab A6)

Ứng dụng Android thực hành Lab A6 môn Lập trình thiết bị di động (LTDD).

## Các tính năng chính
- **Form Đăng ký học phần**: Nhập họ tên, MSSV (10 chữ số), chọn môn học qua Spinner, hệ đào tạo qua RadioGroup, buổi học qua CheckBox (có đếm số buổi đã chọn).
- **Tuỳ chọn nâng cao**: Chuyển đổi thông báo (Switch), mức độ ưu tiên (ToggleButton), và chế độ tối (Dark Mode).
- **Màn hình Xác nhận (ConfirmActivity)**: Hiển thị tóm tắt thông tin đăng ký truyền qua Intent.
